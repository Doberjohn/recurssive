## Why local

Sending every inference to a hosted API means latency you cannot control, a bill
that scales with usage, and user data leaving the device. For a growing class of
features none of that is necessary, because the model is small enough to run where the
data already is.

## What that changes

Latency stops depending on the network. The feature keeps working on a plane.
And the privacy conversation with your customers becomes short, because there is
nothing to explain.
