## Not a rewrite

A full rewrite is the most common way these projects fail. We migrate screen by
screen inside your existing apps, so the native shell keeps shipping while the
shared core grows underneath it.

## Order of work

We start with the screens that change most often, because those are where a
shared codebase pays back fastest, and leave the stable ones for last.
